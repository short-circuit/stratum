# Frontend freeze — closed

The frontend freeze is **over**. This page records what it was and how it
ended, so the policy history stays readable.

## What the freeze was

From the v1.0.0 release until the E12 cutover, the React + Tauri frontend
(`src/`, `src-tauri/`) was frozen as the behavioural and visual reference for
the native gpui rewrite. During that window only bug fixes, security fixes,
documentation, tests and CI maintenance were allowed on `master`; every new
feature landed in the native shell.

The parity plan is `.hermes/plans/2026-11-08_101000-gpui-frontend-implementation.md`
(gitignored working document). Its §3 row table was the acceptance contract.

## How it ended

The cutover deleted `src/`, `src-tauri/`, `e2e/`, `verification/cdp_probe.mjs`,
`package.json`, the npm lockfile and the TypeScript/Vite/Vitest/ESLint/Knip
configuration. The workspace no longer contains a web frontend:

- `crates/stratum-ui` is the shipped desktop application.
- `crates/stratum-mobile` is the Android host of the same shell.
- `stratum-i18n` owns the locale catalogs (the JSON files under `src/i18n/`
  were deleted with the web app).
- `stratum-app` remains the headless service layer every surface calls.

The frozen web build stays available as the `v1.0.0` tag for historical
comparison; no branch is maintained for it.

## Where the parity evidence lives

- `docs/development/parity.md` — the shipped summary of the parity campaign.
- `.hermes/parity/` — the machine-readable reports (`goldens-report.json`,
  `perf-report.json`, `command-parity.md`), regenerated by
  `scripts/verify-gpui-goldens.sh`, `scripts/verify-gpui-perf.sh` and the
  `command_parity` test.
- `goldens/gpui/` — the committed golden screenshots every capture is diffed
  against.

## What replaces the freeze policy

There is one application now, so the freeze rules no longer apply. The rules
that do apply are in `AGENTS.md`: documentation ships with the feature, the
goldens are regenerated when a surface changes, every user-facing string goes
into all eight catalogs, and CI must be green before merge.
